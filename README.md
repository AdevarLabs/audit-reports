## What's in a report

- **Executive summary.** Scope, the exact contracts, commits or components we reviewed, and a short overview of what we found.
- **Assumptions and considerations.** Trust assumptions and design choices, whether stated by the team or identified by us during the review.
- **Findings.** Every issue we found, rated `Critical`, `High`, `Medium` or `Low`, with a description and a recommended fix.
- **Enhancements.** Improvements with no security impact, such as optimizations and code quality suggestions.

## Disclaimer

Reports are provided "as is" and are limited to the scope and timeline described in each one. A report captures a single point in time and does not guarantee a project's future security. Adevar Labs is not liable for any incidents or losses. An audit is not an endorsement of a project.

## About Adevar Labs

Adevar Labs is a web3 security firm built by researchers. Our engineers have spent years breaking and defending production systems, and we work alongside a bench of independent specialists when an engagement calls for it.

Our core work is white-box code review. We read every line in scope ourselves, with no sampling, and we start each engagement by writing down the threat model: what could go wrong, who could cause it, and which assumptions the code relies on. Fuzzing, formal verification and fix reviews come after that. We work mostly in Rust, Solidity and Move, on Solana, Ethereum, Sui, Aptos, Fogo and other EVM and SVM chains.

Beyond audits, we offer PR reviews and continuous security for teams that ship often, as well as infrastructure, penetration testing and operational security assessments for the parts of a protocol that live outside the contracts.

Adevar Labs is part of the SEAL accreditation program, a Solana STRIDE vendor partner, a Circle Alliance Program partner and a Superteam Black recommended auditor. Our founder holds the ETHSecurity Badge.
